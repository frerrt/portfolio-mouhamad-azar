# Portfolio — Mouhamad Azar

Développeur Backend / Full-Stack & Étudiant en M1 Intelligence Artificielle.

Projet Next.js 14 App Router complet et responsive, prêt à être déployé gratuitement sur **Vercel**.

## 🚀 Déploiement sur Vercel (En 2 minutes)

1. Téléchargez et dézippez le fichier `nextjs-portfolio-mouhamad-azar.zip`.
2. Poussez le dossier sur votre compte GitHub (`git init`, `git add .`, `git commit`, `git push`).
3. Connectez-vous sur [Vercel](https://vercel.com).
4. Importez votre dépôt GitHub et cliquez sur **Deploy**.

## 💻 Exécution en local

```bash
npm install
npm run dev
```
